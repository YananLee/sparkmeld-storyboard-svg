# sparkmeld-storyboard-svg

A small local SVG generator associated with [SparkMeld](https://sparkmeld.com/). It does not call the product website or export service.

Install: `npx jsr add @yananlee/sparkmeld-storyboard-svg`. Import `renderStoryboard` from `@yananlee/sparkmeld-storyboard-svg` and render SVG using your own prompts.
